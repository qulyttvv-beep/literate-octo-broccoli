# Boje iz davnina i Kad priroda priča

Dvije uređene knjige u formatu A4, svaka s 23 stranice.

## Preuzimanje

- [Preuzmi bojanku — Boje iz davnina (PDF)](https://github.com/qulyttvv-beep/literate-octo-broccoli/releases/download/knjige-v1/Boje-iz-davnina.pdf)
- [Preuzmi slikovnicu — Kad priroda priča (PDF)](https://github.com/qulyttvv-beep/literate-octo-broccoli/releases/download/knjige-v1/Kad-priroda-prica.pdf)
- [Preuzmi obje knjige zajedno (ZIP)](https://github.com/qulyttvv-beep/literate-octo-broccoli/releases/download/knjige-v1/Obje-knjige.zip)

Bojanka sadrži ilustracije za bojanje, kratke opise bogova, simbole i prijedloge boja. Slikovnica sadrži ilustracije u boji i priče za djecu.

PDF-ovi su dostupni i u mapi [knjige](knjige). Kontrolni zbrojevi nalaze se u [SHA256SUMS](knjige/SHA256SUMS).
